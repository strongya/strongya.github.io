Agent 使用过程中的大模型「降智」现象：机制分析与治理框架

2026/11/9 Arlen AI Agent, LLM, Context Engineering, 工程治理

一、问题定义与分类

1.1 定义

「降智」指用户在长会话、多工具、多步骤的 Agent 使用过程中，主观感知到回答质量、推理深度与指令遵循度随使用时间下降的现象。

1.2 三类成因的分类框架

对「降智」现象的有效治理取决于先验分类。本文将其区分为三类机制上独立的现象：

类型本质可观测特征典型场景
A. 真实能力退化注意力被稀释，信息提取与推理准确率随上下文规模客观下降任务成功率随 token 数/步数渐近或加速下降；新会话中恢复长会话后半段；RAG 注入大量文档后
B. 工程层质量塌陷模型能力未变，系统静默降低了输入上下文的质量质量骤降与特定事件（截断、路由切换、工具报错）在时间上相关静默 compaction；路由错配；工具输出污染
C. 感知层假象输出分布未变，用户期望校准失效抱怨集中于高可见度任务；盲评中差异不显著首次失败后印象固化；与「美化过的早期记忆」对比

三类现象的治理路径互不相同：A 类依赖上下文工程，B 类依赖可观测性建设，C 类依赖预期管理。混同诊断必然导致治理方案错位。

二、机制分析

2.1 上下文与记忆管理失效

Context Rot 实验 [1] 在控制条件下证明：即使全部信息均处于上下文窗口内，模型性能仍随输入 token 数增长而退化；问题与答案的相似度越低，退化越快；干扰项（distractor）的负面效应在长上下文中被放大；连文本复制类机械任务亦受影响。该结果表明退化发生在注意力分配机制层面，而非推理能力层面。

Lost in the Middle 研究 [2] 进一步给出注意力分布的结构特征：信息提取准确率呈 U 型分布，中部位置比首位低 20% 以上；在 closed-book 设定下，多文档问答基线准确率仅 56.1%，且仅 20 篇检索文档（约 2000 tokens）即显著拉低表现。NoLiMa、AbsenceBench 等后续工作表明，主流 NIAH（大海捞针）基准系统性低估了真实退化程度 [2]。

工程层面的三个附加机制：其一，会话超出窗口时的静默截断与摘要压缩是有损过程，关键约束类信息（格式要求、行为边界）最先丢失；其二，缺乏门控的长期记忆会将单次幻觉（如虚假的「用户偏好」）持久化并反复召回，形成自我强化的错误先验；其三，KV 量化、稀疏注意力等降本优化理论上可能引入注意力精度损失，但尚无公开的直接测量，本文将其列为待验证假设而非既定事实。

2.2 管道误差传递

误差级联被证明是智能体可靠性的首要瓶颈 [5]。可靠性科学框架的实测显示：任务时长从 ≤5 分钟增至 ≥120 分钟，成功率下降约 24 个百分点，且衰减呈非线性——越靠后的步骤失败概率越高 [6]。

多智能体系统的失败解剖（MAST 分类法）将 14 类失败归入三大类，占比最高的是系统设计类（FC1，其中步骤重复 FM-1.3 占 15.7%）；任务验证类（FC3）决定内部错误是否以「完成品」形态流出系统 [4]。此外，子代理以摘要形式向主代理回传结果，每个传递 hop 构成一次有损压缩——假设单轮错误率 5%，10 步管道的端到端成功率仅为 0.95¹⁰ ≈ 60%。

2.3 工具数据污染

工具污染分恶意与非恶意两类。恶意层面，工具描述投毒 [7] 与前缀触发的持久化投毒（SEAL）[8] 已被安全研究证明可行，MCP 元数据中的隐藏指令在连接时即生效且用户不可见。非恶意层面在日常退化中影响更大但系统性研究不足（占比待测，无权威统计）：工具返回的海量低质文本直接加剧 context rot；HTTP 错误页被原样注入上下文引发幻觉级联；格式噪音消耗注意力预算；单次污染数据在上下文中全程携带，持续影响后续数十轮。

2.4 路由与工程策略

Routing collapse 研究 [9] 发现：预算宽松时路由器会系统性过度选择强模型，质量-成本权衡发生退化收敛，其根源在于 router 被训练为标量质量预测器，而真实决策是离散排序问题。工程实践中分层路由的误分类（高复杂度查询被路由至弱模型层）用户无感知、聚合仪表盘不可见，被定性为可观测性缺口而非路由算法失败 [10]。此外，prompt caching 的前缀失效重排与采样参数的隐性调整均无透明度承诺，均可引起输出分布漂移。

三、分层治理与业界实践

3.1 战术层：上下文工程

  • Just-in-Time 上下文工程：维护轻量标识符（文件路径、查询、链接），运行时按需加载。Anthropic 于 2025 年 9 月将其系统化为 compaction、记笔记、工具结果清理的组合方案 [11]；Claude Cookbook 提供了对应实现 [12]。该实践已被行业跟进为一种运行时纪律 [13]。
  • 子代理隔离：探索与检索在独立上下文中执行，仅回传压缩结论。Anthropic 多智能体研究系统采用 orchestrator-worker 模式——主代理派生并行子代理并隔离其上下文 [14]；Claude Code 的 subagents/Task 工具基于同一原理 [12]。
  • 定期重置：长任务显式分会话，跨会话状态以结构化文件而非对话历史传递。Claude Code 的 auto-compact（接近 200k 窗口时自动摘要历史）是「定期重置」的产品化实现 [15]；但社区反馈表明压缩会丢失细节 [16]，印证压缩的有损性——重置必须显式、可预期，不能全权交给自动摘要。

3.2 算力与模型层：路由治理

  • 质量阈值与漂移监控：商业 router 已将质量保持率写入优化目标（如以 95%+ 质量为约束训练路由策略）[17]；学术侧的 RouteLLM 在 MT-Bench 上达到与商业路由同性能、成本低 40% 以上 [18]。
  • 反面证据：2026 年复核显示 RouteLLM 自 2024 年 8 月停更、Martian 已下架路由产品 [19]。路由层是持续运营对象而非一次性部署件，缺乏监控时即发生退化收敛（见 §2.4）。
  • 复杂度准入：工具调用轮次多、涉及不可逆动作的查询应强制路由至强模型层；现成网关（OpenRouter auto、LiteLLM Router）默认按成本优化，该规则需在网关策略层显式配置 [19]。
  • 混合检索架构：JIT 的 load-by-reference 即「检索压缩 + 长上下文承载必需原文」的行业标准形态 [11]。

3.3 架构层：记忆、状态与校验

  • 记忆写入门控：写入长期记忆前进行来源、时效、冲突校验，记忆带 TTL 与来源标签。记忆层已成独立品类：Mem0（开源约 6.5 万星，结构化事实抽取 + 语义检索）、Zep/Graphiti（时序知识图谱，episode 级溯源）、Letta/MemGPT（分层自编辑记忆）[20]。但 2026 年中的对比评测显示三者对审计标记与污染召回的支持均不完整，需自研补齐 [21]。
  • 状态机替代自由对话：关键流程使用显式外部状态而非从对话历史推断。图编排框架（如 LangGraph）已将显式状态节点作为默认架构，这与 MAST 中占比最高的 FC1 类失败（步骤重复）直接对应 [4]。
  • 工具输出清洗：schema 校验 → 错误页识别 → 截断 → 摘要的管道化处理，与 programmatic tool calling（大结果不进入窗口）同源 [12]；执行类结果经沙箱/代码执行器返回已是 coding agent 的标配实践。
  • 逐 hop 校验：管道每层出口设置轻量校验器。PROCTOR 证明确定性 guardrails（沙箱、优先级高于 LLM judge 的验收检查）能拦截 judge 本身无法拦截的失败 [22]。成本约束方面，对每次工具调用挂载 LLM judge 将增加 500–2000ms 的 p99 延迟、token 成本翻 2–3 倍 [23]——因此校验必须轻量化并采用采样策略，这不是风格偏好而是硬约束。

四、全生命周期规范

  • 研发阶段：为每个 Agent 定义 context 预算表（系统 prompt、记忆、工具输出、历史各占上限），超限触发显式清理策略而非静默截断；约束类指令结构化、位置固定。
  • 测试阶段：长对话压力测试（50/100/200 轮的成功率衰减曲线）、异常流测试（工具报错、空返回、乱码、超长输出）、路由对抗测试（边界复杂度查询集上的误分类率持续测量）。
  • 运维阶段：轨迹级行为监控（记录每轮 context 构成，使退化可回溯至具体污染事件）、自动熔断（同型错误重复 N 次即中断并升级）、质量分采样盲评（作为静默塌陷的哨兵）。
  • 退役阶段：版本下线时同步清理持久化记忆与缓存前缀，防止「僵尸记忆」被新版本召回。

五、效果评估

治理是否有效应通过衰减曲线而非单次表现判断，指标体系建议如下：

层级指标判据示例
模型层长程成功率衰减曲线（RDC）[6]200 轮时成功率 ≥ 首轮 80%（建议值，按业务校准）
路由层误分类率 + 层间质量分差分差扩大即触发重校准
记忆层记忆命中率 / 污染召回率污染记忆可被审计标记
感知层用户反馈率 / 盲评一致性投诉下降且盲评无差异时，改善的是预期校准而非模型质量；两类信号须分开解读

六、讨论与局限

与流行叙事的分歧：社区流行的「厂商无告知更换或降级模型」假设不可证伪，且 context rot 与误差级联已足以解释绝大多数有实验证据的可复现退化。但需明确划界：厂商透明的成本工程（KV 量化、分层路由、采样参数调整）确实属于 B 类诱因，问题不在于降本本身，而在于其不可观测、不可治理。

局限：其一，KV 量化等对注意力精度的影响缺乏公开测量；其二，非恶意工具污染在「降智」中的占比无权威统计，本文仅给出定性判断；其三，C 类感知偏差无法完全通过工程手段消除，预期管理不可或缺。
